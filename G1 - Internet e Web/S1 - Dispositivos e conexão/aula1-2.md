# Rota 404 — Especificação detalhada da Aula 1.2 - Como meu dispositivo chega à internet?

Este documento especifica de forma detalhada o conteúdo do planeta 1.2 - Como meu dispositivo chega à internet?

## Escopo
- **Faixa etária**: 13 anos ou menos
- **Módulo (Galáxia)**: Internet e Web
- **Assunto (Sistema Planetário)**: Dispositivos e conexão
- **Aula (Planeta)**: 1.2

## Planeta 1.2 (Aula) - Como meu dispositivo chega à internet?

### Objetivo

Apresentar, de maneira visual, a função do Wi-Fi, do roteador e da conexão com a internet.

### Ideia central

**Meu dispositivo não conversa diretamente com a internet de forma mágica: existe uma conexão no caminho.**

### Fluxo da aula

**Cena 1 — O problema**

Um celular aparece tentando abrir uma página.

A tela mostra uma mensagem simples:

`Sem conexão`

Bonzi:

> “Por onde a informação passa?”

**Cena 2 — Wi-Fi**

Surge um símbolo de Wi-Fi entre o celular e um roteador.

Quando o aluno toca no Wi-Fi, ondas animadas aparecem.

Bonzi:

> “Wi-Fi conecta o aparelho à rede sem fio.”

**Cena 3 — O roteador**

O roteador começa a receber pequenos pacotes.

Bonzi:

> “O roteador ajuda a levar os dados para o destino.”

O sistema usa uma animação de fluxo, sem entrar em detalhes técnicos de roteamento.

**Cena 4 — Internet**

O roteador se conecta a uma grande nuvem identificada como `Internet`.

Uma página web aparece dentro dessa nuvem.

O sistema mostra:

`Celular → Wi-Fi → Roteador → Internet → Site`

**Cena 5 — Repetição interativa**

O aluno toca cada parte do caminho.

Ao tocar:

- celular → destaca o dispositivo;
- Wi-Fi → destaca a conexão sem fio;
- roteador → destaca o equipamento;
- internet → destaca a rede externa;
- site → destaca o destino.

**Cena 6 — Microdesafio**

Uma seta desaparece do caminho.

O aluno precisa escolher o elemento faltante.

### Interação

Toque para explorar + escolha do componente ausente.

### Feedback

Bonzi reforça visualmente a relação:

> “Boa! Sem essa parte, o caminho fica interrompido.”

### Encerramento

O caminho completo é animado novamente, desta vez do dispositivo até o site.
