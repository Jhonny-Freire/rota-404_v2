# Rota 404 — Especificação detalhada da Aula 2.1 - Todo dispositivo precisa de um endereço

Este documento especifica de forma detalhada o conteúdo do planeta 2.1 - Todo dispositivo precisa de um endereço

## Escopo
- **Faixa etária**: 13 anos ou menos
- **Módulo (Galáxia)**: Internet e Web
- **Assunto (Sistema Planetário)**: Endereços e sites
- **Aula (Planeta)**: 2.1

## Planeta 2.1 (Aula) — Todo dispositivo precisa de um endereço

### Objetivo

Introduzir o conceito de endereço IP.

### Ideia central

**Um endereço ajuda a identificar para onde os dados devem ir.**

### Fluxo

**Cena 1**

Dois computadores idênticos aparecem.

Bonzi:

> “Para qual deles vai a mensagem?”

Os dois ficam piscando.

**Cena 2**

Cada computador recebe uma etiqueta:

`192.168.0.10`

`192.168.0.20`

A mensagem agora chega ao computador correto.

**Cena 3 — Comparação**

A tela mostra uma casa com um endereço e um dispositivo com um endereço IP.

Bonzi:

> “É como um endereço para encontrar o destino.”

**Cena 4 — Destino**

Uma mensagem começa em um dispositivo e recebe o endereço do destino.

Uma animação leva a mensagem até o dispositivo correspondente.

**Cena 5 — Microteste**

Três dispositivos aparecem com endereços diferentes, um deles indicado por uma borda verde.

O aluno deve enviar a mensagem para o endereço indicado digitando o IP correto.
