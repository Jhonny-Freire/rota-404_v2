## Planeta 3.2 (Aula) — HTML: os blocos de uma página

### Objetivo

Apresentar HTML como estrutura básica de uma página.

### Ideia central

**Uma página pode ser construída com blocos de conteúdo.**

### Fluxo

**Cena 1 — Página pronta**

Mostrar título, texto, imagem e botão.

**Cena 2 — Separação**

A página “se desmonta” em blocos:

`Título`

`Texto`

`Imagem`

`Botão`

Bonzi:

> “Esses blocos formam a estrutura da página.”

**Cena 3 — HTML visual**

Cada bloco recebe uma etiqueta:

`<h1>`

`<p>`

`<img>`

`<button>`

A explicação deve ser visual; não apresentar uma página inteira de código.

**Cena 4 — Montagem**

Os blocos são colocados na ordem correta.

**Cena 5 — Microteste**

O aluno recebe uma página simples e precisa apontar qual bloco representa o título.
