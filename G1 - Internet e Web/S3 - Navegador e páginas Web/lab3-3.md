# Rota 404 — Especificação detalhada da Laboratório 3.3 - Monte sua página

Este documento especifica de forma detalhada o conteúdo do planeta 3.3 - Monte sua página

## Escopo
- **Faixa etária**: 13 anos ou menos
- **Módulo (Galáxia)**: Internet e Web
- **Assunto (Sistema Planetário)**: Navegador e páginas Web
- **Laboratório (Planeta)**: 3.3

## Planeta 3.3 (Laboratório) — Monte sua página

### Tipo

Construtor visual.

### Objetivo

Criar uma página simples usando blocos HTML.

### Tela

À esquerda:

- Título
- Texto
- Imagem
- Botão

Ao centro:

- área de edição

À direita:

- prévia da página

### Fluxo

**Etapa 1 — Estrutura**

O sistema pede:

> “Coloque um título.”

O aluno arrasta o bloco de título para a página.

**Etapa 2 — Conteúdo**

Adicionar um texto.

**Etapa 3 — Elemento visual**

Adicionar uma imagem.

**Etapa 4 — Ação**

Adicionar um botão.

**Etapa 5 — Visualização**

O aluno pressiona `Ver página`.

A estrutura vira uma página visual.

### Regras

O laboratório não deve exigir que o aluno digite código.

O código HTML pode aparecer como recompensa visual depois da montagem:

```html
<h1>...</h1>
<p>...</p>
<img ...>
<button>...</button>
```

Assim, o aluno vê a relação entre ação visual e código sem ter de memorizar sintaxe.

### Variação

Liberar diferentes combinações de conteúdo e permitir pequenas escolhas visuais.
