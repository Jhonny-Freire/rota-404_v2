## Faixa etária de 13 anos ou menos

### Tema da galáxia: Internet e Web

**Objetivo**: fazer o aluno entender, de forma visual e prática, o caminho entre seu dispositivo e um site.

| Sistema Planetário | Planeta                                         | Tipo        | Conteúdo                                                               |
| ---------------------------------------- | --------------------------------------------- | ----------- | ---------------------------------------------------------------------- |
| **1. O que é uma API?**                  | 1.1 — Aplicações que conversam                | Aprendizado | O conceito de API e por que sistemas precisam se comunicar             |
|                                          | 1.2 — Cliente e servidor                      | Aprendizado | Quem solicita, quem responde e qual é o papel de cada sistema          |
|                                          | 1.3 — Faça sua primeira requisição            | Laboratório | Enviar uma requisição para uma API disponibilizada pelo sistema        |
|                                          | 1.4 — Leia a resposta                         | Laboratório | Interpretar os dados retornados pela API                               |
| **2. HTTP na prática**                   | 2.1 — Métodos HTTP                            | Aprendizado | GET, POST, PUT/PATCH e DELETE                                          |
|                                          | 2.2 — Status de resposta                      | Aprendizado | 200, 201, 400, 401, 404 e 500                                          |
|                                          | 2.3 — Monte uma requisição                    | Laboratório | Escolher método, URL, parâmetros e corpo da requisição                 |
|                                          | 2.4 — Resolva o erro                          | Laboratório | Diagnosticar requisições com método, URL ou dados incorretos           |
| **3. JSON e dados**                      | 3.1 — Como a API organiza os dados            | Aprendizado | JSON, objetos, propriedades e arrays                                   |
|                                          | 3.2 — Entendendo um JSON                      | Aprendizado | Ler e localizar informações dentro de uma resposta                     |
|                                          | 3.3 — Extraia os dados                        | Laboratório | Selecionar informações específicas de uma resposta JSON                |
|                                          | 3.4 — Transforme os dados                     | Laboratório | Utilizar os dados recebidos para montar uma nova estrutura             |
| **4. Construindo uma aplicação com API** | 4.1 — Da API para a aplicação                 | Aprendizado | Fluxo completo entre interface, API e dados                            |
|                                          | 4.2 — Regras e autenticação                   | Aprendizado | API key, autenticação e cuidados básicos ao consumir serviços          |
|                                          | 4.3 — Laboratório: criar um consumidor de API | Laboratório | Desenvolver uma pequena aplicação que consulta uma API                 |
|                                          | 4.4 — Desafio final: painel de dados          | Laboratório | Criar uma interface que consulta a API e apresenta os dados ao usuário |

## Faixa etária de 14 anos ou mais

### Tema da galáxia: API Rest

**Objetivo**: fazer o aluno compreender como aplicações trocam informações através de APIs e experimentar esse processo por meio de laboratórios interativos.

| Submódulo                     | Passo                               | Tipo        | Conteúdo                                                                               |
| ----------------------------- | ----------------------------------- | ----------- | -------------------------------------------------------------------------------------- |
| **1. Conhecendo uma API**     | 1.1 — Sistemas que conversam        | Aprendizado | O que é uma API e por que aplicações precisam se comunicar                             |
|                               | 1.2 — Cliente, servidor e API       | Aprendizado | Papel de cada componente na comunicação                                                |
|                               | 1.3 — Faça uma pergunta ao servidor | Laboratório | Escolher uma consulta e enviar uma requisição para uma API simulada                    |
|                               | 1.4 — O servidor respondeu!         | Laboratório | Visualizar a requisição e a resposta acontecendo passo a passo                         |
| **2. Requisições HTTP**       | 2.1 — Como pedir uma informação     | Aprendizado | Conceito de URL, endpoint e requisição HTTP                                            |
|                               | 2.2 — GET, POST, PUT e DELETE       | Aprendizado | O que cada método representa                                                           |
|                               | 2.3 — Qual método devo usar?        | Laboratório | Escolher o método correto para diferentes situações                                    |
|                               | 2.4 — Encontre o problema           | Laboratório | Corrigir uma requisição com método ou endereço incorreto                               |
| **3. Entendendo os dados**    | 3.1 — O que é JSON?                 | Aprendizado | Estrutura de objetos, propriedades e listas                                            |
|                               | 3.2 — Lendo uma resposta            | Aprendizado | Identificação e interpretação de dados retornados                                      |
|                               | 3.3 — Caça ao dado                  | Laboratório | Encontrar uma informação específica dentro de um JSON                                  |
|                               | 3.4 — Monte a resposta              | Laboratório | Organizar dados recebidos para apresentar uma informação corretamente                  |
| **4. API em situações reais** | 4.1 — API em um aplicativo          | Aprendizado | Exemplos de APIs em mapas, previsão do tempo, pagamentos, jogos e redes sociais        |
|                               | 4.2 — Quando algo dá errado         | Aprendizado | Códigos HTTP e problemas comuns                                                        |
|                               | 4.3 — Diagnóstico da API            | Laboratório | Analisar requisição + resposta e descobrir por que uma operação falhou                 |
|                               | 4.4 — Desafio final: missão API     | Laboratório | Resolver uma sequência curta de problemas para recuperar uma informação usando uma API |
