- **Faixa etária**: 13 anos ou menos
- **Módulo (Galáxia)**: Internet e Web

- **Laboratório (Planeta)**: 1.3

## Planeta 1.3 (Laboratório) — Conectando uma rede

### Tipo

Montagem visual / quebra-cabeça.

### Objetivo

Montar uma rede simples usando computador, celular, roteador e internet. Esse formato aplica diretamente o conteúdo definido para o laboratório.

### Tela inicial

À esquerda:

- computador;
- celular;
- roteador;
- ícone de Wi-Fi;
- internet.

À direita:

- uma área vazia chamada `Monte a rede`.

Bonzi:

> “Monte o caminho até a internet.”

### Fluxo

**Etapa 1 — Posicionamento**

O aluno arrasta os elementos para a área de montagem.

O sistema não exige uma posição geométrica exata. O objetivo é a relação lógica.

**Etapa 2 — Conexões**

Depois que os objetos estão no lugar, o aluno deve conectá-los.

O sistema mostra uma linha quando o aluno inicia uma conexão.

**Etapa 3 — Validação**

O aluno pressiona `Testar`.

Se houver um caminho válido, os pacotes começam a circular.

Se não houver, o caminho fica cinza e sem animação.

**Etapa 4 — Descoberta do erro**

O Bonzi destaca somente o primeiro ponto incorreto.

Exemplo:

> “Olhe aqui. O caminho parou.”

O sistema evita revelar toda a resposta.

**Etapa 5 — Conclusão**

Quando a rede está correta:

`✓ Conexão funcionando`

Um pacote percorre:

`Celular/Computador → Wi-Fi → Roteador → Internet`

### Variações

Gerar pequenas configurações diferentes:

- computador + roteador + internet;
- celular + Wi-Fi + roteador + internet;
- dois dispositivos usando o mesmo roteador.
