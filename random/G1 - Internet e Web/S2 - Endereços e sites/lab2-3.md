# Rota 404 — Especificação detalhada do Laboratório 2.3 - Encontrando o destino

Este documento especifica de forma detalhada o conteúdo do planeta 2.3 - Encontrando o destino

## Escopo
- **Faixa etária**: 13 anos ou menos
- **Módulo (Galáxia)**: Internet e Web
- **Assunto (Sistema Planetário)**: Endereços e sites
- **Laboratório (Planeta)**: 2.3

## Planeta 2.3 (Laboratório) — Encontrando o destino

### Tipo

Associação / mapa visual.

### Objetivo

Associar domínios a servidores e endereços em um mapa visual.

### Tela

Mostrar um mapa simplificado com vários servidores.

Exemplo:

- Servidor A — IP 203.0.113.10
- Servidor B — IP 203.0.113.20
- Servidor C — IP 203.0.113.30

No painel lateral aparecem domínios fictícios.

### Fluxo

**Etapa 1**

Bonzi:

> “Encontre onde este site está.”

O aluno recebe um domínio.

**Etapa 2**

O aluno toca no domínio.

O sistema destaca visualmente que ele precisa encontrar o endereço correspondente.

**Etapa 3**

O aluno seleciona um servidor.

**Etapa 4**

Se correto, uma linha conecta domínio → endereço → servidor.

Se errado, a conexão falha e o sistema pede nova tentativa.

### Variações

Trocar a posição dos servidores e dos domínios a cada partida.

### Objetivo didático

O aluno percebe que o nome do site e o endereço usado na rede podem representar coisas diferentes.
