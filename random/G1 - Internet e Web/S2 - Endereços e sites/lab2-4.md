# Rota 404 — Especificação detalhada do Laboratório 2.4 - Missão: encontrar o servidor

Este documento especifica de forma detalhada o conteúdo do planeta 2.4 - Missão: encontrar o servidor

## Escopo
- **Faixa etária**: 13 anos ou menos
- **Módulo (Galáxia)**: Internet e Web
- **Assunto (Sistema Planetário)**: Endereços e sites
- **Laboratório (Planeta)**: 2.4

## Planeta 2.4 (Laboratório) — Missão: encontrar o servidor

### Tipo

Labirinto / percurso lógico.

### Objetivo

Seguir o caminho de um acesso até localizar o servidor correto.

### Tela

Um domínio aparece no topo.

No centro existe um pequeno mapa de caminhos.

Cada caminho representa uma etapa possível da comunicação.

### Fluxo

1. O aluno recebe um destino.
2. Escolhe a próxima etapa.
3. O sistema anima a passagem da requisição.
4. Quando a escolha está correta, o caminho permanece iluminado.
5. Uma escolha errada faz a requisição retornar ao último ponto seguro.
6. O aluno continua até chegar ao servidor correto.
7. O servidor responde e a página aparece.

### Ajuda

Após algumas tentativas, Bonzi pode destacar a direção do próximo passo.
