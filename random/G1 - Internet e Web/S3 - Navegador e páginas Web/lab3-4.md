# Rota 404 — Especificação detalhada da Laboratório 3.4 - Conserte a página

Este documento especifica de forma detalhada o conteúdo do planeta 3.4 - Conserte a página

## Escopo
- **Faixa etária**: 13 anos ou menos
- **Módulo (Galáxia)**: Internet e Web
- **Assunto (Sistema Planetário)**: Navegador e páginas Web
- **Laboratório (Planeta)**: 3.4

## Planeta 3.4 (Laboratório) — Conserte a página

### Tipo

Caça ao erro / correção visual.

### Objetivo

Encontrar e corrigir problemas simples de estrutura.

### Tela

Mostrar uma página quebrada.

Exemplos:

- título aparecendo no lugar errado;
- imagem sem posição;
- botão ausente;
- blocos em ordem incorreta.

Ao lado, mostrar a estrutura em blocos.

### Fluxo

1. Bonzi mostra a página com problema.
2. O aluno toca no elemento quebrado.
3. O sistema destaca o bloco correspondente.
4. O aluno move, troca ou remove o bloco.
5. Pressiona `Testar`.
6. A página é renderizada novamente.
7. Se estiver correta, mostra a versão final.
8. Se ainda houver problema, o sistema destaca somente o próximo ponto relevante.

### Feedback

O sistema deve explicar o efeito da correção. Exemplo:

> “Agora o título está no lugar certo.”
