# Rota 404 - Contexto resumido

Este documento descreve resumidamente o projeto acadêmico Rota 404

## Introdução

O Rota 404 é um sistema de aprendizado sobre tecnologia da informação voltado para o público infantil e juvenil (entre 8 e 16 anos). O sistema aplica didática usando gamificação e elementos visuais, variando a complexidade de acordo com a faixa etária do aluno.

Esse é um projeto acadêmico para uma feira de tecnologia de uma faculdade. A primeira versão foi feita para uma edição passada da feira, sendo essa uma segunda versão do mesmo projeto.

## Sobre o sistema

### Estrutura do aprendizado

- Faixas etárias
  - Módulos
    - Assuntos
      - Aulas (aprendizado)
      - Laboratórios (atividades práticas)

Faixa etária diz repeito a uma faixa de idade. Exemplo: 10-14 anos

Módulo diz repeito a um tema. Exemplo: Internet.

Assunto diz respeito a um assunto dentro do tema. Exemplo: Dispositivos e Conexões (dentro do módulo Internet)

Aulas são pontos de aprendizado dentro do assunto. Todas as aulas usam em maior parte elementos visuais sinéticos e às vezes interagíveis. Elas possuem poucos textos, havendo narração para eles.

Laboratórios são atividades práticas dentro do assunto, sempre seguidas de uma ou mais aulas. Os laboratórios podem funcionar de diversas formas, como: desafios, quebra-cabeças, questionários, aplicações, entre outros (não se limitando a isso). Costumam ter menos texto ainda (com excessões), que também são narrados.

Cada faixa etária tem N módulos. Cada módulo tem N assuntos. Cada assunto tem N aulas e N laboratórios.

### Tema

O sistema é tematizado em espaço sideral e exploração intergalática e interplanetária.

Módulos são representados por galáxias, assuntos são representados por sistemas planetários, aulas e laboratórios são representados por planetas.

O usuário navega pelo mapa em um foguete.

Existe um co-piloto chamado "Bonzi Buddy", que é diretamente inspirado no spyware viral Bonzi Buddy. Ele possui possui diversos diálogos em todo o sistema, dando contexto, instruções, explicações, entre outros. Quase sempre ele é quem fala com o usuário ao invés de apenas apresentar um texto na tela.

### Gameficação

- Pontuação:

    O usuário recebe uma pontuação para cada laboratório finalizado. A soma da pontuação dos laboratórios reflete na pontuação total do assunto. A soma da pontuação dos assuntos reflete na pontuação total do módulo.
    - Rankings de pontuação
      - Por módulo
      - Por assunto
      - Não possui ranking por laboratório

- Conquistas

    O usuário consegue conquistas variadas de formas diversas.

- Personagens

    O usuário escolhe um avatar para representá-lo durante as aulas e laboratórios
